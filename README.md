<h1>Chess</h1>

<p>In this project, I recreated the game of Chess, a strategic masterpiece. This project explores object oriented programming, inheritance, and wraps everything together in a GUI.</p>

Key Features:
<ol>
  <li>Reactive GUI Chess Board.</li>
  <li>All Chess pieces move as intended.</li>
  <li>Undo button.</li>
</ol>

Instructions:
<ol>
  <li>Clone repository.</li>
  <li>Run "java src/chess/ChessGUI.java" in the root directory of the project.</li>
</ol>
